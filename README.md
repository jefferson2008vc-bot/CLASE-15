El objetivo de esta actividad es aplicar el uso de colecciones de datos en Python mediante el desarrollo de un programa sencillo que permita almacenar, organizar y mostrar información utilizando estructuras como listas, resolviendo un problema de la vida real.
En este proyecto se implementa una lista para gestionar el registro de nombres de estudiantes, cumpliendo con las siguientes acciones:
-Crear una lista con estudiantes iniciales
-Agregar nuevos estudiantes a la lista
-Eliminar estudiantes registrados
-Recorrer y mostrar todos los estudiantes registrados
El código se encuentra disponible en este repositorio público de GitHub, tal como lo requiere la actividad.
